# 🧪 Laboratorio de Inyección SQL – Node.js + MySQL

Este proyecto es un laboratorio educativo diseñado para **demostrar vulnerabilidades de inyección SQL** y cómo prevenirlas usando buenas prácticas en aplicaciones desarrolladas con **Node.js**, **Express** y **MySQL**.

---

## 🚀 Tecnologías utilizadas

- **Node.js** – entorno de ejecución JavaScript.
- **Express** – framework para construir APIs y servidores web.
- **MySQL** – base de datos relacional.
- **Bootstrap 5** – diseño del frontend.
- **Dotenv** – manejo de variables de entorno.
- **Cors** – control de acceso entre dominios.

---

## 📦 Instalación
1. Clonar el repositorio.
2. Renombrar el archivo `.env.template` a `.env`.
3. Configurar las variables de entorno en el archivo `.env`.
4. Ejecutar la base de datos con `docker-compose up -d`.
5. Abre tu gestor de bases de datos (por ejemplo, MySQL Workbench) y ejecuta el script `bd.sql`, para crear la base de datos del laboratorio.
6. Ejecutar el servidor con `npm run start`.
7. Acceder a la aplicación en `http://localhost:3000/index.html`
